# MY 365 DIARY

日々の1枚を、撮った日のマスに切り抜いて貼っていく写真日記です。

- 写真を選ぶと、撮影日（写真の情報）を読み取って、その日のマスに貼ります
- 写真の主役（人・ペット・料理など）を自動で切り抜きます。体が写真の端で切れているときは、丸く切り抜きます
- 写真のない日は、黒い星か短いメッセージが入ります
- 「画像として保存」で、その月のカレンダーをA3縦の画像（1754×2480px）として書き出せます
- ホーム画面に追加すると、アプリのように使えます

## プライバシー

写真はすべて、使っている端末のブラウザの中（IndexedDB）にだけ保存されます。
サーバーには送られません。切り抜きもブラウザの中で行います。

切り抜きに使うAIモデル（約90MB）は、初回だけ staticimgly.com から読み込みます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| index.html | 画面の骨組み |
| style.css | 見た目 |
| app.js | カレンダーの表示、写真の追加、日付パネル |
| cutout.js | 写真の切り抜き |
| export.js | 画像として保存 |
| db.js | 端末への保存（IndexedDB） |
| sw.js / manifest.webmanifest | オフライン対応・ホーム画面に追加 |
| vendor/ | 外部ライブラリ（切り抜き、撮影日の読み取り）とそのライセンス |

ビルドは不要です。フォルダをそのまま静的サイトとして公開できます。

## 注意

- iPhoneのSafariは、長い間開かないサイトのデータを消すことがあります。ホーム画面に追加して使うと消えにくくなります。
- プライベートブラウズでは写真を保存できません。
